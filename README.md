# TravelBuddy

Wakes you up during a journey when you get close to your destination, using GPS instead of a clock. Built with Flutter for Android and iOS on the Enate SDLC Factory.

- Product requirements: [PRD.md](PRD.md)
- Engineering contract: [Technical-Context.MD](Technical-Context.MD)
- Domain glossary: [Context.MD](Context.MD)
- Contribution and branching rules: [CONTRIBUTING.md](CONTRIBUTING.md)

## Getting started

Mobile app (Flutter, `mobile/`): install the Flutter stable SDK, then `flutter pub get`, `flutter test`, `flutter run`.

Backend (.NET, `backend/`): install the .NET SDK, then `dotnet build` and `dotnet test`.

The projects are created by the first delivered Stories.
